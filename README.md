# Christian Partnership for the Confined Ministry Inc

A warm, editorial single-page responsive website for **Christian Partnership for the Confined Ministry Inc** — an Evangelical Church based in Cagayan de Oro, Philippines.

## Features & Highlights

- **Design Aesthetics**: Custom Warm Terracotta & Cream color palette with typography powered by Google Fonts (`Playfair Display` headlines paired with `Inter` UI).
- **Responsive Layout**: Mobile-first architecture supporting 375px, 768px, and 1280px breakpoints.
- **Semantic Structure**: Modern HTML5 elements (`<header>`, `<nav>`, `<section>`, `<footer>`, `<aside>`) with accessible navigation drawer and search modal.
- **Sections Included**:
  1. Sticky Header & Mobile Navigation Drawer
  2. Hero Section with Mission Statement
  3. Newsletter Strip & Subscription Form
  4. Community of Worship Feature
  5. Events & News (Featured Event: Thanksgiving Party)
  6. Community of Justice Feature
  7. Location & Gathering Info
  8. Footer with Contact Details & Social Media Links

## Local Development

Launch a simple HTTP server to view the site:

```bash
# Python
python -m http.server 3000

# Or Node / npx
npx serve .
```

Then navigate to `http://localhost:3000` in your web browser.
